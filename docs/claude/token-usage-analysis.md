# 에이전트 토큰 사용량 분석 (2026-10-12)

대상: 에이전트1의 DM 세션 `759ceeb0-…` 로그 1개. 기간은 10/10 01:55부터 10/12 10:05까지이고, 들어온 메시지 19건, API 호출 119회, 스크린샷 98장이 기록돼 있다. 모델은 claude-opus-5-5.

## 결론

- 비용의 대부분은 같은 DM 세션을 `--resume`으로 계속 이어 쓰면서 **스크린샷이 맥락에 계속 쌓이는 것**에서 나온다.
- 맥락은 5.8k 토큰에서 시작해 약 100k 토큰까지 커졌다. 스크린샷 한 장이 약 1.4k 토큰이다.
- 큰 맥락의 캐시가 깨지면, 다음 호출 한 번에 그 맥락 전체를 다시 캐시에 쓴다. 이 비용이 가장 크다.
- 고정 비용(시스템 프롬프트와 CLAUDE.md, 5.8k)과 확장 사고(총 7.2k)는 주원인이 아니다.

## 비용 구성

단가는 로그의 `costUSD`에서 역산했다. 입력 $4, 출력 $20, 캐시 읽기 $0.2, 캐시 쓰기 $8 (100만 토큰당)이다. 캐시는 1시간 TTL이다.

| 항목 | 토큰 | 비용 | 비중 |
|---|---|---|---|
| 캐시 쓰기: 1시간 넘게 쉰 뒤 재개 (2회) | 184k | $1.47 | 24% |
| 캐시 쓰기: 대화 도중 맥락이 줄며 캐시가 깨짐 (2회) | 148k | $1.19 | 20% |
| 캐시 쓰기: 새 스크린샷 등 증분 | 158k | $1.26 | 21% |
| 캐시 읽기 (매 호출마다 누적 맥락 전체) | 7.2M | $1.44 | 24% |
| 출력 (사고 포함) | 33k | $0.66 | 11% |
| 합계 | | $6.02 | |

- "오늘의 상태를 말해주세요" 답장은 호출 3번이었지만 $0.84가 들었다. 51시간 만의 재개여서 96k 맥락 전체를 다시 썼기 때문이다.
- 같은 종류의 답장도 캐시가 살아 있는 상태에서는 $0.06~0.15였다.
- 대화 도중 맥락이 99k→66k, 113k→89k로 줄어든 일이 두 번 있었다. Claude Code가 오래된 도구 결과를 정리한 것으로 추정된다. 이때마다 시스템 프롬프트 뒤쪽의 캐시가 모두 깨져 62k와 86k를 다시 썼다.
- 10/10 02:32에 5시간 한도에 도달했다. 이 시점까지 에이전트가 쓴 양은 약 $1.4였으므로, 같은 계정의 다른 사용(개발 세션 등)이 한도를 함께 소모했다.

## 코드에서 토큰을 많이 쓰는 지점 (Claude Desktop 대비)

| # | 지점 | 코드 위치 | Claude Desktop과의 차이 |
|---|---|---|---|

| 3 | 답장 한 번 = API 호출 여러 번 | 프롬프트 `src/agent/prompts.ts:37,41,42`, 도구 설명 `src/tools/desk-tools.ts:14` | Desktop은 답 한 번에 호출 1번이다. 여기서는 "먼저 screenshot → cmd+k 이동 → 입력 → 확인 screenshot"에 "조작할 때마다 확인" 규칙이 더해져 평균 6.6회 호출, 스크린샷 5.4장이 든다. 호출마다 누적 맥락 전체를 다시 읽는다. |

| 7 | 기타 텍스트 | 🔔 배지 `src/tools/server.ts:70`, 턴 마무리 "작업 기록" `prompts.ts:54` | 영향이 작다. |

구조적 제약: `Engine.run({ prompt, sessionId })` 인터페이스(`src/engine/types.ts`)는 대화 기억을 엔진 내부의 불투명한 세션에 맡긴다. 그래서 무엇을 맥락에 남길지(텍스트만 남기고 오래된 화면은 버리는 등)를 런타임이 정할 수 없다. Desktop처럼 맥락을 관리하려면 대화 기록의 소유권을 런타임 쪽으로 옮기는 인터페이스 변경이 먼저 필요하다.

## 개선 방향

1. **메시지(또는 작업)마다 새 세션을 연다.** DM의 최근 대화는 수신 쪽(Socket Mode)에서 텍스트로 넣어 준다. 이 로그로 시뮬레이션하면 $6.02가 약 $3.23으로 줄어 46% 절감된다. 장시간 공백 후 첫 답장은 $0.84에서 약 $0.10 수준이 된다.
2. 스크린샷 토큰을 줄인다. 해상도를 낮추거나 Slack 창 영역만 잘라서 찍는다. 남는 비용의 큰 부분이 장당 약 1.4k 토큰의 이미지 쓰기다.
3. 선택 사항:
   - 엔진을 저장소 밖의 빈 폴더에서 실행해 개발용 CLAUDE.md가 실리지 않게 한다.
   - 단순한 Slack 응대에는 더 가벼운 모델을 쓴다.
